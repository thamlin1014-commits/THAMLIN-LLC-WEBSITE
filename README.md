# THamlin LLC Website

A responsive multi-page business website for THamlin LLC as it grows into web development and IT services.

## Pages
- Home — company introduction and service overview
- About — company direction, values, and approach
- Services — web development, IT support, and digital solutions
- Contact — email contact and a client-side inquiry form

## Built with
- HTML5
- CSS3 (responsive layouts and mobile navigation)
- Vanilla JavaScript

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Contact
thamlin1014@gmail.com

## Contact form note
The form prepares an email in the visitor's default email application. It does not store or transmit submissions to a server.

## Deployment
A GitHub Actions workflow is included at `.github/workflows/pages.yml` for GitHub Pages deployment.
